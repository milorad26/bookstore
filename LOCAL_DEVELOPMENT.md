# Local development

The backend uses Spring's `local` profile by default. It uses the file-backed H2 database at `bookstore/data/bookstore`, a local-only development JWT signing key, and permits the Vite frontend at `http://localhost:5173`. Stripe checkout requires your own Stripe test keys: set `STRIPE_SECRET_KEY` and `STRIPE_PUBLISHABLE_KEY` in the backend process environment before starting it. Keep those keys out of source control and do not reuse the previously committed key.

Cloudflare Turnstile protects public contact submissions and new account registration outside the local profile. Local development is preconfigured with Cloudflare's public test site and secret keys, so the visible widget and backend verification work without additional setup. These test keys always pass and are only for development; replace them with your own keys in deployment. The frontend site key is in the ignored `bookstore-frontend/.env.local` file. The backend test secret key is a local-only default and can be overridden with `TURNSTILE_SECRET_KEY`; never expose a real secret key to the frontend. Set `CAPTCHA_ENABLED=false` only if you explicitly need to disable local verification.

Start the backend from `bookstore` with `./mvnw spring-boot:run` (Windows: `mvnw.cmd spring-boot:run`). Start the frontend from `bookstore-frontend` with `npm run dev`. The Vite proxy forwards `/api` requests to `http://localhost:8080`.

For production, set `SPRING_PROFILES_ACTIVE` to a production profile, and supply `JWT_SECRET` (a unique random secret), `CORS_ALLOWED_ORIGINS`, `DATABASE_URL`, `DATABASE_DRIVER`, `DATABASE_USERNAME`, `DATABASE_PASSWORD`, the Stripe keys, `TURNSTILE_SECRET_KEY` for the backend, and `VITE_TURNSTILE_SITE_KEY` when building the frontend through the deployment environment or secret manager. CAPTCHA verification is enabled by default outside the local profile. Never reuse the local development key. The H2 console is available only in the local profile. Use the same shared database across backend instances so revocations are visible to every instance.
